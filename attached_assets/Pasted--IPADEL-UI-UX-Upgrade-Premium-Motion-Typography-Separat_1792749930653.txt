# IPADEL — UI/UX Upgrade: Premium Motion, Typography & Separate Pages

Act as a senior creative frontend engineer and motion designer specializing in premium sports-club websites.

You have already built the IPADEL digital menu. The current implementation is functional, but it feels static, lacks visual energy, and does not provide a sufficiently polished premium experience.

**Upgrade the existing project in place. Do not rebuild it from scratch. Do not remove any existing working functionality.**

Keep the original IPADEL branding, the deep navy background, neon-green accents, white typography, the supplied logo, the product details modal, and the locally persistent Memory Basket.

Your mission is to make the website feel alive, sophisticated, smooth, and professionally designed.

## 1. Separate Drinks and Canteen into Independent Pages

Replace the single-page category-switching approach with distinct pages:

- `/index.html` — Main landing page.
- `/drinks.html` — Dedicated Drinks menu.
- `/canteen.html` — Dedicated Canteen page.

If the current project already uses a router or a different working page structure, adapt the routing without introducing an unnecessary framework.

### Landing page

Create a premium, immersive IPADEL landing page featuring:

- The original IPADEL logo.
- A visually striking hero section.
- The headline `FUEL YOUR GAME.`
- The supporting text `Good drinks. Great games.`
- Two distinct destination cards: `DRINKS` and `CANTEEN`.
- Beautiful imagery, restrained neon-green lighting, and elegant entrance animations.
- A visible Memory Basket entry point.

Clicking Drinks must navigate to the dedicated Drinks page.

Clicking Canteen must navigate to the dedicated Canteen page.

Do not put the full product catalog on the landing page.

### Drinks page

Create a dedicated drinks browsing experience with:

- A refined page heading: `THE DRINKS BAR`
- A short subtitle: `REFRESH YOUR GAME.`
- Working category filters.
- Working product search.
- Premium product cards.
- Product-details modal or drawer.
- Quantity selection.
- Add-to-Memory functionality.
- A persistent Memory Basket accessible from the header.

Keep all current placeholder products clearly marked as demo data until the real menu arrives.

### Canteen page

Create a dedicated Canteen page with its own visual identity while retaining the shared IPADEL brand system.

Use a premium coming-soon experience:

`THE CANTEEN`

`YOUR NEXT BREAK IS LOADING.`

`OUR CANTEEN MENU IS COMING SOON.`

Use subtle sports-inspired visual details and a strong back-to-menu action.

Do not add food products until the real inventory is provided.

## 2. Add High-Quality Animation Throughout the Experience

The existing website feels static. Introduce purposeful motion across the entire interface.

Do not simply add random animations to every element. Motion must guide attention, improve perceived quality, and feel consistent.

### A. Hero entrance

On initial page load:

- Animate the hero eyebrow with a subtle fade and upward movement.
- Reveal the headline using a smooth staggered word animation or a restrained masked text reveal.
- Bring in the supporting copy with a short delay.
- Animate the primary navigation cards with a gentle upward entrance.
- Reveal the hero image with a subtle scale and opacity transition.
- Add a slow, almost imperceptible movement to decorative background lighting.

Use a carefully choreographed sequence lasting approximately 800–1400ms overall.

Avoid excessive delays that make the website feel slow.

### B. Scroll-triggered reveal

Use GSAP with ScrollTrigger if the dependency can be installed correctly in the current project.

Otherwise, use IntersectionObserver and CSS transitions.

Animate:

- Section headings.
- Product-grid entrances.
- Featured drink imagery.
- Promotional elements.
- Footer content.

Use staggered reveal timing for product cards.

Elements should animate only when entering the viewport, not repeatedly on every tiny scroll movement.

Respect `prefers-reduced-motion`.

### C. Product-card interactions

Make product cards feel interactive and premium.

On hover:

- Slightly lift the card.
- Smoothly scale the product image.
- Add a subtle border-color transition.
- Introduce a restrained green highlight.
- Reveal or emphasize the details action.
- Animate the quick-add icon with a smooth rotation or scale transition.

Suggested timing: 250–450ms with a refined ease such as `power2.out`.

Use small, controlled movements. No sudden jumps, exaggerated bounce, or aggressive glowing effects.

On touch devices, maintain clear tap feedback without relying on hover.

### D. Product-details modal

Upgrade the details modal with:

- A smooth backdrop fade.
- A subtle modal scale-and-rise entrance.
- Smooth image presentation.
- Refined quantity-control feedback.
- An animated confirmation toast when a product is saved.

The modal must remain accessible and responsive.

All existing modal behavior must continue working.

### E. Memory Basket animations

Preserve the existing basket logic and localStorage persistence.

Add:

- A small badge pop when the saved quantity changes.
- A smooth drawer entrance and exit.
- A subtle product-row entrance when adding an item.
- Smooth quantity updates.
- An animated empty-state transition.
- A short toast notification: `ADDED TO MEMORY BASKET`.

Do not add checkout or online-order functionality.

### F. Navigation transitions

Navigation between the landing page, Drinks page, and Canteen page should feel cohesive.

Use lightweight page-transition effects where practical.

Do not introduce blank screens, unnecessary loading delays, or complex routing dependencies.

All pages must work correctly when opened directly by URL and when refreshed.

## 3. Upgrade Typography to a Professional Design System

The current typography needs refinement.

Use a consistent combination of:

- **Space Grotesk** for bold, distinctive display headings.
- **Inter** for body text, product descriptions, labels, and interface controls.

If these fonts are unavailable, provide clean sans-serif fallbacks.

Use a restrained typographic scale:

- Hero headline: large, bold, and tightly composed.
- Page titles: strong uppercase display typography.
- Section headings: medium-large and highly legible.
- Product names: clear and confident.
- Prices: prominent, with neon green used selectively.
- Supporting text: comfortable line height and muted blue-gray.
- Small labels: uppercase with subtle letter spacing.

Avoid using too many font weights, excessive letter spacing, tiny product descriptions, or oversized text everywhere.

Make the typography feel like a premium sports brand rather than a gaming dashboard.

Load fonts efficiently and use appropriate fallback behavior.

Keep the supplied IPADEL logo unchanged.

## 5. Add Subtle Sports-Club Atmosphere

Use elegant visual details inspired by a modern padel club:

- Very subtle court-line patterns.
- Fine grid textures.
- Soft moving light reflections.
- Small neon-green indicators.
- Minimal technical labels.
- Occasional thin-line separators.

These details must stay in the background and never interfere with readability.

Do not use a noisy animated background or distracting particle effects.

## 6. Performance and Technical Quality

Keep the project pure HTML, Tailwind CSS, and Vanilla JavaScript.

GSAP and ScrollTrigger are permitted as animation libraries, but do not introduce React, Vue, or another framework.

Requirements:

- No animation library loaded repeatedly.
- No duplicated event listeners.
- No layout shifts caused by image loading.
- Animate primarily with transform and opacity.
- Avoid expensive continuous animations.
- Pause or simplify background motion when appropriate.
- Use `will-change` only when justified.
- Support keyboard navigation.
- Maintain visible focus states.
- Respect reduced-motion preferences.
- Preserve Memory Basket data between all pages.
- Ensure navigation works on desktop and mobile.
- Keep product data separate from rendering logic.

Do not overwrite or discard existing working files without inspecting them first.
